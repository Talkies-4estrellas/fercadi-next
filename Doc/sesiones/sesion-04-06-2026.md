# Sesión 04-06-2026 — Generación de tips con IA

## Objetivo del día
Probar y refinar la generación automática de tips de construcción con Groq/IA.

---

## Lo que se hizo

### 1. Primer intento de generación de tips
- **Commit:** `primer intento de generacion`
- **Archivos:** `src/app/admin/tips/nuevo/page.tsx`, `src/app/api/admin/tips/ia/route.ts`
- **Problema:** El flujo de generación de tips con IA necesitaba refinamiento — el prompt no producía contenido consistente y el formato del JSON devuelto a veces fallaba.
- **Solución:** Se ajustó el prompt del sistema para Groq:
  - Se forzó la respuesta en JSON puro `{ titulo, descripcion, contenido }` con instrucción explícita de no incluir texto fuera del JSON
  - Se agregó validación del JSON devuelto antes de guardarlo
  - Se agregó manejo de error en el UI para cuando la IA falla
- **Resultado:** La generación produce tips en Markdown bien estructurados con título, descripción y contenido extenso.

---

## Verificación
`/admin/tips/nuevo` genera tips coherentes sobre materiales de construcción usando Groq Llama 3.3 70B.
