# Sesión 28-05-2026 — Integración de IA (Gemini → Groq)

## Objetivo del día
Implementar generación automática de tips con IA y resolver el problema con la API key.

---

## Lo que se hizo

### 1. Primer intento con Google Gemini
- **Commit:** `implementación de una clave de Gemini`
- **Archivos:** `src/app/api/admin/tips/ia/route.ts`, `.env.local`
- **Problema:** Se quería generar tips de construcción automáticamente con IA.
- **Intento:** Se configuró la API de Google Gemini con `GEMINI_API_KEY` en `.env.local`.
- **Resultado:** Funcionó localmente pero hubo problemas con el push: la API key quedó expuesta en el código en lugar de en variables de entorno.

### 2. Problema con API key en git
- **Commit:** `error de push por api key`
- **Problema:** GitHub rechazó el push porque detectó una API key de Google expuesta en el historial.
- **Solución:** Se limpió el historial y se movió la key a `.env.local` con `.gitignore` correcto.

### 3. Cambio a Groq
- **Commit:** `cambio a Grop` (sic)
- **Archivos:** `src/app/api/admin/tips/ia/route.ts`, `.env.local`
- **Problema:** Gemini tenía limitaciones en el plan gratuito y complejidad de configuración.
- **Solución:** Se migró a Groq con el modelo `llama-3.3-70b-versatile`. La API de Groq es compatible con el formato de OpenAI y tiene free tier de 14,400 req/día sin tarjeta.
  - Variable: `GROQ_API_KEY=gsk_...`
  - Prompt: devuelve JSON `{ titulo, descripcion, contenido }` con Markdown en `contenido`
- **Resultado:** Generación de tips con IA funcional y más rápida que Gemini.

## Verificación
