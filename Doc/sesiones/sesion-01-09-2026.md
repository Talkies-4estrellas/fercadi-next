## Cambios realizados

### 1. Fix hidratación — `ChatProducto.tsx`
**Problema:** React reportaba mismatch: el servidor renderizaba `aria-hidden="true"` en el `<i>` del branch sin usuario, pero el cliente no lo incluía.  
**Solución:** Se agregó `aria-hidden="true"` explícito en JSX línea 126.  
**Pendiente:** El servidor de desarrollo (Turbopack) necesita reinicio completo para limpiar caché; el error de consola persiste hasta entonces.

### 2. Fix typo categoría especializados — `[producto]/page.tsx`
`const CATEGORIA = 'especialisados'` corregido a `'especializados'`. Causa raíz de todos los 404 en esa sección.

### 3. Componente `DescripcionExpandible.tsx` (nuevo)
Componente cliente que limita `descripcion2` a ~4 líneas con botón "Ver más / Ver menos". Usa `useRef` + `useEffect` para medir `scrollHeight` real y solo muestra el botón si el texto desborda `MAX_H = 112px`.

### 4. Estilos `.secVerMasWrap` y `.secVerMasBtn` — `product.module.css`
Botón pill translúcido sobre la banda azul oscura. Hover con fondo suave blanco.

### 5. `ProductoDetalle.tsx` — usa `DescripcionExpandible`
Reemplazado `<p>` plano por `<DescripcionExpandible texto={descripcion2} />` en el bloque de segunda descripción.

### 6. Nuevo endpoint `GET /api/admin/categorias` (nuevo archivo)
Devuelve categorías activas por sección (`?seccion=textucos`). Llama a `getCategorias()` existente. Requiere header `x-usuario-id` de admin.

### 7. Selector dinámico de categorías — `ProductoForm.tsx`
**Problema original:** Campos "Categoría · Slug" y "Categoría · Nombre Visible" eran inputs de texto libre — error-prone para usuarios no técnicos.  
**Solución:** Reemplazados por un `<select>` que carga categorías existentes al montar y al cambiar sección. Opción "+ Nueva categoría…" expande los inputs de texto para casos nuevos.  
**Bug corregido:** StrictMode de React invocaba el effect dos veces, limpiando `categoria_slug` en modo editar. Solución final: separar en `fetchCategorias(seccion, limpiar)` + `useEffect` solo sobre `user`, y llamar `fetchCategorias(..., true)` desde el `onChange` del select de sección.

## Análisis y decisiones

- **Estructura de datos:** Todos los productos (concretos, textucos, ferretería) comparten la tabla `productos` distinguida por columna `seccion`. El `slug` forma la URL junto a `seccion/categoria_slug/slug`.

- **Hidratación persistente:** El fix de `aria-hidden` está en el archivo pero Turbopack necesita restart para servir el bundle actualizado al cliente.
