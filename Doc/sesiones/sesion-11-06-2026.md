## Lo que se hizo

### 1. Sistema de comentarios en productos
- **Commit:** `cambios importantes`
- **Archivos:** `src/app/api/comentarios/route.ts`, `src/components/ComentariosProducto.tsx`, páginas de detalle de producto
- **Problema:** Los productos no tenían ninguna forma de interacción del usuario.
- **Solución:** 
  - Se creó la tabla `comentarios_productos` en Supabase con campos `producto_id`, `usuario_id`, `nombre`, `comentario`, `calificacion (1-5)`, `creado_en`
  - Se implementó la API REST en `/api/comentarios` (GET por producto_id, POST para crear)
  - Se creó el componente `ComentariosProducto` (Client): lista de comentarios con estrellas + formulario para agregar
  - Se integró en las páginas de detalle de ferretería, concretos y textucos (8 páginas en total)
- **Resultado:** Los usuarios autenticados pueden dejar comentarios con calificación en todos los productos.
