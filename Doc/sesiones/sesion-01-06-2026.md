# Sesión 01-06-2026 — Corrección de imágenes y bugs

## Objetivo del día
Resolver problemas con las imágenes de productos y corregir bugs encontrados tras el deploy.

---

## Lo que se hizo

### 1. Corrección de imágenes
- **Commits:** `corrección de imágenes y el código`, `corrección de errores y bugs`
- **Archivos:** `src/lib/imagen.ts`, páginas de detalle de producto
- **Problema:** Algunos productos mostraban imágenes rotas o no mostraban imagen cuando `imagen_url` era null. El componente `next/image` lanzaba errores con URLs inválidas.
- **Solución:** Se creó/mejoró `src/lib/imagen.ts` con la función `resolverImagenProducto()` que:
  - Devuelve `null` si la URL es nula o vacía
  - Valida que la URL sea absoluta o relativa válida
  - Maneja el fallback a un placeholder cuando no hay imagen
- **Resultado:** Las imágenes se muestran correctamente o muestran un placeholder; sin errores en consola.

### 2. Corrección de bugs generales
- **Problema:** Tras el primer deploy en Vercel se detectaron varios bugs: rutas que rompían, datos null sin manejar, y componentes que fallaban en SSR.
- **Solución:** Revisión general de páginas con datos opcionales, agregando `?? []` y `?? 0` donde correspondía. Se aseguró que los componentes Client tuvieran `'use client'` correctamente.
- **Resultado:** Build de Vercel pasando sin errores.
