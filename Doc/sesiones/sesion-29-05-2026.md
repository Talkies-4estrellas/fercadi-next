## Lo que se hizo

### 1. Primer deploy en Vercel
- **Commit:** `vercel`
- **Archivos:** Configuración de Vercel, variables de entorno en el panel de Vercel
- **Problema:** El proyecto solo funcionaba localmente.

### 2. Corrección de regex en el parser de contenido
- **Commits:** `regex`, `corrección`, `2 intento`
- **Archivos:** `src/app/tips/[slug]/page.tsx` o componente de renderizado de Markdown
- **Problema:** El contenido Markdown generado por IA no se mostraba bien en el sitio; los caracteres especiales y el formato de listas/encabezados fallaban.
- **Solución:** Se ajustaron las expresiones regulares del parser Markdown para manejar correctamente `##`, `**texto**`, `-` listas y saltos de línea.
- **Resultado:** El contenido de los tips se renderiza correctamente con formato.
