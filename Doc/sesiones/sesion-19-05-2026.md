## Objetivo del día
Implementar la vista del panel de administración y conectar el archivo CSS de estilos del admin.

## Lo que se hizo

### 1. Panel de administración inicial
- **Commit:** `Cambios con el apartado de administrador y conexión a un archivo CSS`
- **Archivos:** `src/app/admin/page.tsx`, `src/styles/admin.module.css`
- **Problema:** No existía ninguna interfaz para gestionar el contenido del sitio.
- **Solución:** Se creó el panel admin con:
  - Layout con sidebar de navegación
  - Módulo de gestión de productos (listado básico)
  - CSS Module propio (`admin.module.css`) con variables de la identidad visual FERCADI
  - Guard básico de rol: solo usuarios con `rol = 'admin'` pueden acceder
- **Resultado:** Primer panel de administración funcional.
