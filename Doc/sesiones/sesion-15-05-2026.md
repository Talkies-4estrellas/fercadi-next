# Sesión 15-05-2026 — Migración a base de datos

## Objetivo del día
Reemplazar todos los datos estáticos (hardcoded) por datos reales provenientes de Supabase/PostgreSQL.

---

## Lo que se hizo

### 1. Configuración de Supabase y capa DB
- **Archivos:** `src/lib/db.ts`, `.env.local`
- **Problema:** Los productos, categorías y contenido estaban hardcodeados en el código.
- **Solución:** Se creó `src/lib/db.ts` — adaptador propio sobre `pg` que convierte placeholders `?` a `$1, $2…` (estilo mysql2) y agrega `RETURNING *` automáticamente a INSERT. Se configuró `DATABASE_URL` en `.env.local`.
- **Resultado:** Capa de acceso a DB compartida por todas las páginas y APIs.

### 2. Eliminación de datos estáticos
- **Commit:** `Migración a base de datos completada y borrado de los datos estáticos`
- **Archivos:** múltiples páginas en `src/app/`
- **Solución:** Todas las páginas cambiadas a `async` con `await db.query(...)`. Datos de productos, categorías y tips ahora vienen de la base de datos.
- **Resultado:** El sitio refleja los datos reales de Supabase.

### 3. Creación de tablas en Supabase
- **Tablas creadas:** `usuarios`, `productos`, `materiales_categorias`, `tips`
- **Resultado:** Esquema inicial con datos de prueba cargados.

## Verificación
Productos y categorías cargando desde Supabase en todas las secciones.
